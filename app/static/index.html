When you add a photo, SimplyDoors stamps it with the time and where it was taken, so the office can see deliveries were checked in the right place.

  • Location is used only at the moment you add a photo.

iPhone: stop it from asking again

iPhones ask about location again every day or so. To make it a one-time thing:

  1. Open Settings → Apps → Safari
  2. Tap Location
  3. Choose Allow
